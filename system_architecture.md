# Paintify Web contracts

- The C++ painter and WebGPU GL subset stay unchanged in structure. `StyleParams` and the GLSL Style uniform block must have identical vec4-aligned layouts. Experimental settings append four floats after the old arrays; legacy saved looks contain 260 floats, current looks 264. Accept both lengths and default new settings off for legacy looks.
- Experimental state is independent of brush-material selection and `s.enabled`. `runPost(styleEffects)` uses ordinary finish stages only when the base style is enabled; the explicit experimental gate can run alone. Effects write the final output, never temporal `m_canvasTex`. Mosaic reads the immutable source texture; no neighboring concurrent output reads.
- Keep requested smoothing sigma in `g_params`; render through a temporary copy with effective zero when disabled. Browser saved looks add an ordinary `# paintify-tensor-on=0/1` comment to retain switch state independently of amount. Old files without the comment retain sigma-based behavior.
- `web/video-export.js` owns capability negotiation, abortable bounded seeks and encoder backpressure. The app owns one export session with an AbortController, waits for the paint pump, locks source/settings changes, and restores controls in finally. Export samples a constant estimated frame rate, emits silent MP4 and buffers muxed bytes in memory. Camera recording captures session name/chunks/display/stream locally and stops canvas-stream tracks on completion.
- `Display.destroy()` releases its uniform buffer/context but never destroys borrowed source textures. Main display owns its uploaded source texture.
- CI builds shaders and Wasm, runs existing brush tests, new render/look regressions, helper unit tests and real browser export/recording checks. Preview artifacts allow local inspection without deploying a branch. Do not treat source-only checks as a renderer build pass.
